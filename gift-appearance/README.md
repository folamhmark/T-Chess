# Gift Appearance

Отдельная страница «Кэшбэк в подарок — ваш» с плавным появлением подарка и зигзагообразным стиранием белого снежного слоя на Anime.js.

[Открыть страницу](https://folamhmark.github.io/T-Chess/gift-appearance/) · [Исходный экран Figma](https://www.figma.com/design/AjN75rJn2AFTKCodA15ef8/?node-id=316-22740)

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 3000
```

Открыть http://localhost:3000/gift-appearance/. Сборка и установка зависимостей не нужны. Можно также открыть `index.html` из этой папки в браузере.

## Состав

- `index.html` — семантическая структура экрана и настоящие кнопки/ссылка.
- `styles.css` — композиция 375 × 812 и адаптация под узкие экраны.
- `app.js` — масштабирование, Anime.js timeline, стирание снега и управление повтором.
- `vendor/anime.min.js` — локальная библиотека Anime.js; лицензия MIT рядом.
- `assets/` — локальные исходные изображения/векторы из Figma.
- `assets-manifest.json` — соответствие ассетов слоям Figma и эталонные позиции.

## Что перенесено

Подарок, оба слоя снега, белое свечение, системная строка, подписи и рисунки текста — из оригинального макета. Растровая графика экспортирована в 2×, маска подарка и исходное отсечение сохранены в прозрачном PNG. Картинки не перерисованы и не сгенерированы заново. Полный скриншот экрана не используется как часть страницы. В коде нет временных URL Figma.

Текстовые рисунки экспортированы в SVG из оригинальных SF Pro Rounded / SF Pro Text, чтобы вид совпадал с макетом на Windows и Linux, где этих шрифтов может не быть. Заголовок, подпись и названия кнопок остаются в HTML и доступны скринридеру. При изменении текста нужно обновить HTML-подпись и соответствующий SVG из Figma. Файлы шрифтов не распространяются.

## Слои анимации

| Селектор | Назначение |
| --- | --- |
| `#gift-layer` | Подарок вместе с оригинальным передним снегом и маской. Можно менять opacity/transform. |
| `#gift-glow` | Белое свечение, отдельный векторный слой. |
| `#snow-layer` | Фоновый снег. |
| `#snow-blur-layer` | Размытый фоновый снег. |
| `#reward-copy` | Заголовок и подпись. |
| `#floating-actions` | Нижние действия. |
| `#snow-burst` | Полноэкранный canvas белого снежного слоя, поверх композиции. |

Анимация автоматически запускается один раз после загрузки изображений. Повтор — кнопкой справа от экрана или нажатием на подарок. На узких viewport справа отображается компактная круглая кнопка. Текст и действия появляются после основного движения подарка. Белый слой закрывает весь экран и стирается широкой мягкой кистью зигзагом слева направо и обратно, сверху вниз. Вдоль края стирания движутся 220 небольших снежинок размером 2–6,8 px; хлопушек нет. Итоговая композиция совпадает с исходным макетом.

### Тайминг

Общая длительность — **2680 мс**. Характер — игровой: подарок делает мягкий пружинящий выход с небольшим overshoot, после него последовательно появляются заголовок, подпись и кнопки.

| Время от запуска | Эффект |
| --- | --- |
| 0–80 мс | Подарок скрыт: opacity 0, translateY 48 px, scale 0,88. Текст и кнопки также скрыты. |
| 80–780 мс | Проявление подарка 0→1 с `easeInOutSine`. |
| 80–860 мс | Выход подарка к translateY −6 px и scale 1,035 с `easeOutCubic`. |
| 860–1220 мс | Возврат к translateY 0 и scale 1 с `easeInOutSine`. |
| 140–1190 мс | Исходное белое свечение проявляется с opacity 0,25→1. |
| 0–80 мс | Экран полностью покрыт белым снегом. |
| 80–2020 мс | Мягкий ластик стирает снег зигзагом сверху вниз, `easeInOutSine`. |
| 1720–2280 мс | Заголовок: opacity 0→1, translateY 18→0 px, scale 0,95→1. |
| 1840–2340 мс | Подпись: opacity 0→1, translateY 14→0 px. |
| 2060–2600 мс | Основная кнопка: opacity 0→1, translateY 18→0 px. После появления разрешается нажатие. |
| 2180–2680 мс | Ссылка «На главную»: opacity 0→1, translateY 14→0 px. После появления снимается `inert`. |
| 2680 мс | Конечное состояние, анимация завершена. |

Текст и действия используют `easeOutCubic`; их тайминги сохранены. Подарок движется под белой маской и становится виден по мере стирания. Маска — Canvas 2D с `destination-out`: семь проходов широкой кисти со скруглёнными краями и мягкой кромкой 12 px. Кисть занимает 36% высоты экрана. Последние 10% движения плавно очищают остаточную кромку. Маской управляет локальная Anime.js, DOM-частиц нет. Стирание замедлено на 380 мс (1560 → 1940 мс), задержки текста и кнопок сохранены. Canvas не перехватывает нажатия.

При `prefers-reduced-motion: reduce` сразу виден конечный экран без движения и белой маски. Включение настройки во время проигрывания завершает эффект. При скрытии вкладки или изменении ширины текущий эффект также завершается. Повторный запуск сначала очищает прошлый timeline и маску, поэтому они не накапливаются. Если библиотека не загрузилась, основной экран остаётся видимым.

В консоли доступны ссылки на элементы:

```js
await window.giftAppearance.ready;
const { gift, glow, snow, snowBlur, copy, actions } = window.giftAppearance;

window.giftAppearance.replay();
window.giftAppearance.finish();
// window.giftAppearance.isPlaying — состояние проигрывания.
// window.giftAppearance.timeline — текущий экземпляр Anime.js для инспекции.
// window.giftAppearance.particleCount — число живых частиц, 0 после завершения.

window.giftAppearance.setGiftVisible(false);
window.giftAppearance.setGiftVisible(true);

// Библиотека доступна как window.anime.
// После finish() можно подключить свой вариант движения:
// anime({ targets: gift, opacity: [0, 1], translateY: [24, 0], duration: 1000 });
```

`gift` и `glow` находятся внутри `.gift-canvas`: родитель отвечает за масштаб экрана. Анимировать нужно сами слои, чтобы не перезаписывать масштаб родителя. PNG подарка включает снег из исходной иллюстрации: это оригинальная группа, а не отдельная вырезка коробки без снега. Для отдельных ленточек или крышки понадобятся дополнительные исходные слои.

## Действия

Кнопка приза заблокирована, а ссылка инертна до завершения своих появлений. «Забрать приз» отправляет всплывающее DOM-событие `gift:claim`. Реального начисления или ложного сообщения об успехе нет.

```js
document.addEventListener('gift:claim', ({ detail }) => {
  // detail: { milestone: 10, rewardType: 'cashback' }
  // Здесь подключается реальная выдача приза.
});
```

Начало анимации отправляет событие `gift:animationstart`, завершение — `gift:animationend` с `detail.reason`.

«На главную» ведёт в корень GitHub Pages проекта. Оба элемента доступны с клавиатуры и имеют видимый фокус.

## Эталонная геометрия

Экран — 375 × 812, радиус 32. Статусная строка — 44, пустой app bar — 44, иллюстрация — 382. Текстовый блок начинается на y = 470; заголовок имеет исходный контейнер 327 × 82. Кнопка приза — x = 16, y = 642, 343 × 56, радиус 16, цвет #FFDD2D. Домашний индикатор — 133 × 5, снизу 8. Цвет текста — #333333, ссылки — #428BF9.

На ширинах меньше 375 изображения и текстовая композиция масштабируются вместе, а кнопки остаются реальными элементами. На коротком экране доступна вертикальная прокрутка; содержимое не обрезается ради заполнения viewport.

### Свободный разлёт снега

220 снежинок рождаются вдоль края стирания в течение 100–1600 мс его движения. Позиция рождения фиксируется: после этого частица не привязана к кисти. У каждой собственные направление, скорость, сопротивление воздуха, гравитация, покачивание и вращение. Жизнь — 600–950 мс с мягким появлением и затуханием. Стирание по-прежнему занимает 1940 мс; свободный снежный хвост завершается к 2680 мс вместе с анимацией экрана. Распределение повторяемо при перезапуске.
