# Задачи дня: счётчик, бабл и шторка

Готовый прототип экрана шахматного марафона из Figma, узел `2053:40854`. Шторка «Верный ход» — по узлам `775:80218` и `122:53911`.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны. Либо из этой папки выполните `python3 -m http.server 3000` и откройте http://localhost:3000.

## Управление

- «Завершить задачу» справа открывает шторку «Верный ход».
- «Ого, погнали дальше» закрывает её и запускает следующую задачу.
- Цифры 1–5 выбирают задачу; «Повторить анимацию» повторяет бабл и счётчик.
- Escape закрывает шторку без перехода; «Замедлить ×3» замедляет движение.
- Учитывается системная настройка уменьшения движения.

## Файлы

- `index.html` — элементы экрана и оригинальные отдельные ассеты Figma, встроенные как data URL для переносимости. Полного скриншота экрана в реализации нет.
- `styles.css` — оформление, доска из 64 клеток, бабл и шторка.
- `app.js` — состояния и анимации на Anime.js.
- `vendor/` — Anime.js 3.2.2 и лицензия MIT.

Персонаж выгружен в 3× разрешении. Тексты задач 2–5 демонстрационные. Появление бабла: подъём 8 px, масштаб .95→1, 440 мс; текст — перекрывающиеся проявления символов по 240 мс с интервалом 18 мс и лёгким снятием размытия. Шторка появляется за 460 мс, закрывается за 260 мс; переход к следующей задаче происходит после закрытия.

## Прогресс задач

Верхний бар показывает завершённые задачи: 0 → 20 → 40 → 60 → 80 → 100%. Он растёт при появлении шторки «Верный ход», сохраняет значение при продолжении и повторе анимации. После пятой задачи кнопка продолжения запускает новый круг с нуля. Выбор задачи цифрой задаёт соответствующее число предыдущих завершённых задач. Escape не отменяет уже засчитанный результат.

Заполнение занимает 620 мс с плавным торможением; внутри полосы есть тонкая светлая грань и однократный мягкий блик. При уменьшении движения значение меняется сразу.
