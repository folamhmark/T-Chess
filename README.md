# T-Chess
T-Chess Prototype

Интерактивный прототип экрана марафона на HTML, CSS и Anime.js 3.2.2.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```sh
python3 -m http.server 3000
```

Перейдите на http://localhost:3000. Сборка и установка зависимостей не требуются.

## Файлы

- `index.html` — экран и SVG-иконки.
- `styles.css` — оформление.
- `app.js` — состояния и анимация прогресса.
- `vendor/anime.min.js` — локальная копия Anime.js.

## Поведение

Доступны переходы 0→1, 2→3, 9→10, 10→11 и 19→20. Обычные точки — 8×8 px. Свёрнутый участок содержит три точки по 4×4 px с промежутками 4 px. Значки этапов — 32×32 px. Подпись засчитанного дня — #428BF9. Учитывается настройка уменьшения движения.

Иконки воссозданы в SVG по предоставленным изображениям. Характер движения вдохновлён [richbox](https://github.com/mishanaer/richbox).
