# Gift Appearance — Animation Specification

Спецификация принятого прототипа «Кэшбэк в подарок — ваш». Дата: 17 ноября 2026. Визуальный эталон: `gift-motion-12`: исходный эффект версии 11 с дополнительной белой паузой 500 мс перед запуском. Все времена эффекта в разделах 1–11 — в миллисекундах от запуска исходного timeline ПОСЛЕ белой паузы. Для времени от начала сценария прибавлять 500 мс.

- [Открыть прототип](https://folamhmark.github.io/T-Chess/gift-appearance/?v=gift-motion-12)
- [Макет Figma](https://www.figma.com/design/AjN75rJn2AFTKCodA15ef8/?node-id=316-22740)
- [Код анимации](app.js), [геометрия и стили](styles.css), [карта исходных ассетов](assets-manifest.json)

## 1. Сценарий и результат

Экран награды за 10 активных дней шахматного марафона. В начале белый снежный слой закрывает всю композицию. Широкая мягкая кисть стирает его зигзагом сверху вниз, открывая фон и подарок. От кромки отделяются снежинки: после рождения они летят независимо, замедляются, покачиваются и падают. Затем последовательно появляются заголовок, подпись и действия. Последние снежинки продолжают падать поверх уже открытого экрана.

Длительность исходного эффекта — **3280 мс**, общая длительность с новой паузой — **3780 мс**. Стирание заканчивается в **2020 мс**, текст и кнопки полностью появляются к **2680 мс**. Анимация одноразовая, без зацикливания. Конечное состояние совпадает с макетом.

Заголовок: «Кэшбэк в подарок — ваш». Подпись: «Набрали 10 дней в игре, так держать». Основное действие: «Забрать приз». Вторичное: «На главную».

## 3. Слои

| Слой | Содержимое и поведение |
| --- | --- |
| Фоновая сцена | Градиент, `#snow-layer`, `#snow-blur-layer` |

## 4. Состояния и переходы

| Состояние | Вид и доступность | Переход |
| --- | --- | --- |
| Загрузка | При разрешённом движении подарок, текст и действия скрыты через `motion-enabled`; кнопка повтора отключена. Чистый белый CSS-слой закрывает экран до готовности ассетов; маска Canvas создаётся при подготовке запуска | Все изображения завершили decode/load → запуск |
| Начало, 0–80 | Белая маска закрывает весь экран; подарок opacity 0, translateY 48 px, scale 0,88. Текст и действия скрыты. Основная кнопка disabled, ссылка inert | Автоматически → стирание |
| Открытие, 80–2020 | Снег стирается; подарок движется под маской; рождаются свободные снежинки | В параллель запускаются текст и действия |
| Появление контента, 1720–2680 | Заголовок, подпись, кнопки появляются с индивидуальными задержками; снег может проходить перед ними | Основная кнопка активна с 2600, ссылка с 2680 |
| Снежный хвост, 2020–3280 | Белой маски нет, оставшиеся снежинки независимо падают и затухают | Автоматически → завершено |
| Завершено | Подарок, свечение, текст и действия opacity 1, временные transform сброшены; Canvas очищен, список частиц пуст, timeline остановлен и удалён | Повтор или действие пользователя |
| Повтор | Текущий timeline остановлен, Canvas и частицы очищены; параметры восстановлены; новый запуск с нуля | В начало; наложения запусков нет |
| Reduced motion | Сразу конечный экран, без маски, движения и снежинок | Повтор также оставляет конечный экран |
| Прерывание | При скрытии вкладки или изменении ширины экрана немедленно устанавливается конечный экран | Возврат к вкладке сам по себе не перезапускает эффект |
| Anime.js недоступна | После ожидания изображений показывается конечный экран; повтор отключён | Статичный экран доступен |

Ошибки декодирования отдельных изображений не блокируют запуск: используется catch/fallback. Повторной загрузки и отдельного error UI в прототипе нет. Если основной скрипт вообще не инициализировался, ранний HTML-скрипт через 4000 мс снимает `motion-enabled`, открывая статичную композицию.

## 6. Стирание белого снега

Реализация: Canvas 2D, белая заливка и удаляющий stroke с `globalCompositeOperation = destination-out`. Зигзаг идёт слева направо, затем обратно, постепенно вниз. Восемь опорных точек образуют семь диагональных проходов. Широкая кисть выходит за границы экрана, поэтому развороты происходят снаружи.

Для ширины W, высоты H и индекса i = 0…7:

```text
x(i) = −0,22 × W для чётного i; 1,22 × W для нечётного i
y(i) = H × (−0,06 + 0,16 × i)
ширина кисти = 0,36 × H
lineCap = round; lineJoin = round
shadowBlur = 12 × W / 375
```

Локальное время снега τ начинается на 80 мс общей шкалы. Прогресс пути:

```text
u = clamp(τ / 1940, 0, 1)
p = (1 − cos(π × u)) / 2
пройденная длина = p × полная длина зигзага
```

На последних 10% пространственного прогресса остаточная мягкая кромка дополнительно удаляется плавно через `smoothstep((p − 0,9) / 0,1)`. После τ = 1940 мс белая заливка больше не рисуется. Canvas остаётся для свободных снежинок до конца общего timeline.

## 7. Свободные снежинки

300 — общее число частиц за запуск, не число одновременно видимых снежинок. Часть ещё не родилась, часть уже исчезла или находится за пределами экрана. При повторе распределение воспроизводится: seed 7641, генератор LCG с множителем 1664525, слагаемым 1013904223 и модулем 2³².

Параметры при W = 375; линейные величины масштабируются на s = W / 375.

| Параметр | Значение |
| --- | --- |
| Цвет | Белый #FFFFFF |
| Рождение | τ = 100–1600 мс, то есть 180–1680 мс общей шкалы |
| Время жизни | 1000–1500 мс |
| Радиус | 1,4–4,5 px; диаметр 2,8–9 px |
| Форма | Эллипс с полуосями r и 0,85r |
| Базовая скорость | 35–145 px/с, направление 0…2π |
| Горизонтальная вариативность | Дополнительно от −22,5 до +22,5 px/с |
| Вертикальная скорость | Радиальная компонента минус 30 px/с |
| Гравитация | 70–160 px/с² |
| Сопротивление воздуха | Коэффициент 1,8 с⁻¹ |
| Амплитуда покачивания | 3–11 px, фаза индивидуальна |
| Угловая частота покачивания | 7 рад/с |
| Вращение | Начальная фаза + 1 рад/с |
| Максимальная opacity | 0,85 |
| Проявление | Первые 70 мс жизни, smoothstep |
| Исчезновение | После 45% жизни, плавно до 0 к 100% |

Позиция рождения рассчитывается один раз по положению кисти в момент рождения, с радиальным смещением от её центра. Расстояние до центра: `0,18H + (random − 0,65) × 32s`. Угол смещения случайный. После рождения положение частицы не пересчитывается относительно кисти: нет жёсткой привязки, движения кольцом или синхронного разворота с ластиком.

Для времени t в секундах после рождения:

```text
drag(t) = (1 − exp(−1,8t)) / 1,8
flutter(t) = [sin(phase + 7t) − sin(phase)] × amplitude
x(t) = x0 + vx × drag(t) + flutter(t)
y(t) = y0 + vy × drag(t) + 0,5 × gravity × t²
opacity = smoothstep(age / 70)
        × [1 − smoothstep((age / lifetime − 0,45) / 0,55)] × 0,85
```

`smoothstep(v)` здесь: сначала ограничить v диапазоном 0…1, затем вычислить v²(3−2v). Скорость постепенно гасится сопротивлением, гравитация продолжает тянуть вниз. Частица удаляется по окончании жизни. Снежный clock работает линейно 3200 мс; easing стирания вычисляется отдельно, чтобы физика частиц не ускорялась и не замедлялась вместе с кистью.

## 8. Управление и интеграция

Запуск — автоматически после ожидания всех изображений внутри экрана. Повтор — кнопкой справа от телефона или нажатием на подарок. На узком viewport кнопка повтора компактная, круглая; это управление просмотром прототипа, вне композиции макета. Во время запуска у неё `aria-busy=true`; повтор во время движения разрешён и начинает новую анимацию с нуля.

Основная кнопка заблокирована до 2600 мс. После появления отправляет всплывающее событие:

```js
screen.dispatchEvent(new CustomEvent('gift:claim', {
  bubbles: true,
  detail: { milestone: 10, rewardType: 'cashback' },
}));
```

Прототип не начисляет награду, не показывает результат запроса и не блокирует повторное нажатие после события. Реальное начисление, защита от повторной выдачи и состояния сетевого запроса относятся к интеграции с продуктом.

Ссылка «На главную» имеет `inert` до 2680 мс; после этого ведёт в `../`, корень GitHub Pages проекта.

| Событие | Когда | Данные |
| --- | --- | --- |
| `gift:animationstart` | После запуска timeline | Без detail |
| `gift:animationend` | При завершении или принудительном finish активного запуска | `{ reason }` |
| `gift:claim` | По нажатию активной кнопки | `{ milestone: 10, rewardType: 'cashback' }` |

Причины завершения: `completed`, `reduced-motion`, `backgrounded`, `resize`; ручной `finish()` использует `finished`. При перезапуске прежний запуск останавливается без отдельного события завершения. При немедленном показе статичного экрана из-за reduced motion или отсутствия библиотеки события начала и завершения не отправляются.

API `window.giftAppearance`: `ready`, `replay()` / `play()`, `finish(reason)`, `isPlaying`, `timeline`, `particleCount`, `setGiftVisible(boolean)` и ссылки на слои. `particleCount` считает живые частицы по возрасту, включая те, что находятся за границей Canvas. `setGiftVisible` завершает движение без события завершения и показывает/скрывает подарок для отладки.

## 9. Адаптивность и доступность

Изображения и текстовая композиция масштабируются на W / 375. На мобильном экран ограничен шириной 375 px; минимальная высота — 812 px, на более высоком viewport экран может растягиваться. На коротком экране используется вертикальная прокрутка. Кисть рассчитывается относительно фактической высоты, частицы и размытие — с учётом масштаба ширины.

При `prefers-reduced-motion: reduce` сразу виден конечный экран. Включение настройки во время движения немедленно завершает эффект. Кнопки имеют доступные названия и видимый keyboard focus. Декоративные SVG/Canvas скрыты от скринридера; скрытый визуально текст остаётся доступен. В прототипе видимость текста управляется opacity, отдельной задержки его чтения скринридером нет.

## 10. Производительность и проверка

Anime.js подключена локально из `vendor/`. Один Canvas обслуживает маску и все частицы; отдельные DOM-узлы для снежинок не создаются. Внутреннее разрешение Canvas — CSS-размер × min(devicePixelRatio, 2). После завершения timeline останавливается, Canvas очищается, массив частиц освобождается. Фоновые бесконечные анимации отсутствуют.

Локально в Chromium проверены: длительность 3280 мс, наличие живых снежинок после 2800 мс, очистка по завершении, повторный запуск, доступность основной кнопки, отсутствие ошибок JavaScript. В предыдущих итерациях также проверялись reduced motion и белая маска в начале/середине/конце стирания.

На физическом iPhone 12 и в мобильном Safari FPS пока не измерялся. Плавность на нём ожидается, но 60 FPS не подтверждены измерением. При переносе в продукт проверить холодный запуск, повтор, фон/возврат и reduced motion на реальном устройстве. Основной потенциально дорогой участок — полноэкранная перерисовка и `shadowBlur`, а не только количество частиц. Оптимизация при необходимости: уменьшение внутреннего разрешения Canvas и стоимости мягкого края с сохранением принятого вида.

## 11. Критерии приёмки

- В начале проигрывания весь экран белый; сцена открывается зигзагом сверху вниз с мягкими краями, без хлопушек и колец.
- К 2020 мс белая маска полностью убрана; подарок занимает исходное положение без остаточного смещения/масштаба.
- Снежинки отделяются от кромки, летят независимо от кисти и продолжают падать после стирания. Частицы различаются размером, направлением, скоростью и временем исчезновения.
- Заголовок, подпись и действия появляются по указанным таймингам; текст не появляется весь одновременно.
- Основная кнопка доступна с 2600 мс, ссылка с 2680 мс, независимо от продолжающегося снежного хвоста.
- К 3280 мс движущегося снега нет, композиция совпадает с макетом, анимация остановлена.
- Повторы не накапливают частицы и timeline. Reduced motion, скрытие вкладки и изменение ширины корректно приводят к конечному экрану.
- Исходные изображения сохранены; белое свечение не превращается в отдельную яркую вспышку.

## 12. Белая пауза перед запуском — версия 12

До исходной анимации добавлен статичный белый экран длительностью **500 мс**. Белый слой закрывает только телефон целиком, включая системную строку и нижние действия. Внешняя кнопка повтора остаётся видимой. Пауза не содержит fade, частиц, движения или вспышки. Она начинается после подготовки ассетов на первом входе и немедленно при каждом последующем повторе. Время загрузки ассетов не входит в 500 мс.

До готовности ассетов чистый белый вид обеспечивается ранним классом `motion-enabled`. Во время паузы используется `.reward-screen.anticipating::after` с белым фоном и z-index 25. После 500 мс слой снимается, начинается прежний timeline; Canvas уже содержит белую маску, поэтому промежуточного кадра со сценой нет. Сохраняется исходный белый интервал 0–80 мс: заметное начало эффекта приходится примерно на 580 мс общей шкалы.

| Момент общей шкалы | Поведение |
| --- | --- |
| 0–500 мс | Чистый белый экран, timeline не проигрывается |
| 500 мс | Запуск исходного timeline, событие `gift:animationstart` |
| 580 мс | Начало движения подарка и стирания |
| 2520 мс | Белая маска убрана |
| 3100 мс | Активна основная кнопка |
| 3180 мс | Активна ссылка «На главную» |
| 3780 мс | Финальная очистка и конечное состояние |

Один отменяемый таймер хранится в `leadInTimer`. `stop()` очищает его и снимает класс белого слоя; token защищает от устаревшего запуска. Повтор в ожидании начинает новые 500 мс, не оставляя старый отложенный запуск. `finish`, уход вкладки в фон, изменение ширины и включение reduce приводят сразу к конечному экрану. При reduce до старта или отсутствии Anime.js пауза пропускается. `isPlaying=true` уже во время ожидания, `timeline` создан, но paused; событие animationstart означает фактическое начало эффекта после ожидания. Событие animationend при принудительном завершении возможно и во время ожидания.

Приёмка: в 0–499 мс виден только белый телефон; timeline.play не вызван. На 500 мс запускается ровно один исходный timeline. Его параметры, ассеты и относительные задержки совпадают с версией 11. Повтор на 300 мс отменяет первый запуск; новый начинается не ранее чем через 500 мс после повтора. Принудительное завершение до старта отменяет будущую анимацию. В reduce конечная композиция открывается сразу. Проверки длительности 3280 мс в разделе 10 относятся к самому эффекту предыдущей версии, новая полная длительность — 3780 мс.
