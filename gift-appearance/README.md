# Gift Appearance

Отдельная страница «Кэшбэк в подарок — ваш» для дальнейшей работы над появлением подарка.

[Открыть страницу](https://folamhmark.github.io/T-Chess/gift-appearance/) · [Исходный экран Figma](https://www.figma.com/design/AjN75rJn2AFTKCodA15ef8/?node-id=316-22740)

## Запуск

Из корня репозитория:

```sh
python3 -m http.server 3000
```

Открыть http://localhost:3000/gift-appearance/. Сборка и установка зависимостей не нужны. Можно также открыть `index.html` из этой папки в браузере.

## Состав

- `index.html` — семантическая структура экрана и настоящие кнопки/ссылка.
- `styles.css` — композиция 375 × 812 и адаптация под узкие экраны.
- `app.js` — масштабирование иллюстрации и точки подключения будущей анимации.
- `assets/` — локальные исходные изображения/векторы из Figma.
- `assets-manifest.json` — соответствие ассетов слоям Figma и эталонные позиции.

## Что перенесено

Подарок, оба слоя снега, белое свечение, системная строка, подписи и рисунки текста — из оригинального макета. Растровая графика экспортирована в 2×, маска подарка и исходное отсечение сохранены в прозрачном PNG. Картинки не перерисованы и не сгенерированы заново. Полный скриншот экрана не используется как часть страницы. В коде нет временных URL Figma.

Текстовые рисунки экспортированы в SVG из оригинальных SF Pro Rounded / SF Pro Text, чтобы вид совпадал с макетом на Windows и Linux, где этих шрифтов может не быть. Заголовок, подпись и названия кнопок остаются в HTML и доступны скринридеру. При изменении текста нужно обновить HTML-подпись и соответствующий SVG из Figma. Файлы шрифтов не распространяются.

## Слои для будущей анимации

| Селектор | Назначение |
| --- | --- |
| `#gift-layer` | Подарок вместе с оригинальным передним снегом и маской. Можно менять opacity/transform. |
| `#gift-glow` | Белое свечение, отдельный векторный слой. |
| `#snow-layer` | Фоновый снег. |
| `#snow-blur-layer` | Размытый фоновый снег. |
| `#reward-copy` | Заголовок и подпись. |
| `#floating-actions` | Нижние действия. |

Страница загружается в конечном статичном состоянии. Автоматической анимации появления пока нет. Размеры, скругление, маски и свечение самой композиции сохранены.

В консоли доступны ссылки на элементы:

```js
const { gift, glow, snow, snowBlur, copy, actions } = window.giftAppearance;

window.giftAppearance.setGiftVisible(false);
window.giftAppearance.setGiftVisible(true);

// Пример подключения своей анимации:
// animate(gift, { opacity: [0, 1], translateY: [24, 0] });
```

`gift` и `glow` находятся внутри `.gift-canvas`: родитель отвечает за масштаб экрана. Анимировать нужно сами слои, чтобы не перезаписывать масштаб родителя. PNG подарка включает снег из исходной иллюстрации: это оригинальная группа, а не отдельная вырезка коробки без снега. Для отдельных ленточек или крышки понадобятся дополнительные исходные слои.

## Действия

«Забрать приз» отправляет всплывающее DOM-событие `gift:claim`. Реального начисления или ложного сообщения об успехе нет.

```js
document.addEventListener('gift:claim', ({ detail }) => {
  // detail: { milestone: 10, rewardType: 'cashback' }
  // Здесь подключается реальная выдача приза.
});
```

«На главную» ведёт в корень GitHub Pages проекта. Оба элемента доступны с клавиатуры и имеют видимый фокус.

## Эталонная геометрия

Экран — 375 × 812, радиус 32. Статусная строка — 44, пустой app bar — 44, иллюстрация — 382. Текстовый блок начинается на y = 470; заголовок имеет исходный контейнер 327 × 82. Кнопка приза — x = 16, y = 642, 343 × 56, радиус 16, цвет #FFDD2D. Домашний индикатор — 133 × 5, снизу 8. Цвет текста — #333333, ссылки — #428BF9.

На ширинах меньше 375 изображения и текстовая композиция масштабируются вместе, а кнопки остаются реальными элементами. На коротком экране доступна вертикальная прокрутка; содержимое не обрезается ради заполнения viewport.
