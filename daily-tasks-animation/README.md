# Задачи дня: счётчик, бабл, шторка и финал

Готовый прототип экрана шахматного марафона из Figma, узел `2053:40854`. Шторка «Верный ход» — по узлам `775:80218` и `122:53911`.

[Подробная спецификация: состояния, оформление, motion и критерии приёмки](specification.md)

## Запуск

Откройте `index.html` в браузере. Можно также запустить `python3 -m http.server 3000` из корня репозитория и открыть http://localhost:3000/daily-tasks-animation/. Сборка и установка зависимостей не нужны.

## Управление

- «Завершить задачу» справа открывает шторку «Верный ход».
- В задачах 1–4 «Ого, погнали дальше» закрывает шторку и запускает следующую задачу.
- В пятой задаче «ОК» запускает финал. Шторка закрывается, пингвин уходит вниз за снег и доску, затем экран растворяется в белый. После белой паузы снежная маска раскрывает экран «Задача дня решена!».
- Нажатие на экран успеха после появления «Коснитесь, чтобы продолжить» начинает новый круг.
- «Повторить финал» снова открывает шторку пятой задачи. «Начать заново» открывает первую задачу и сбрасывает прогресс.
- Цифры 1–5 выбирают задачу; «Повторить анимацию» повторяет бабл и счётчик.
- Escape закрывает шторку без перехода; «Замедлить ×3» замедляет движение.
- Учитывается системная настройка уменьшения движения.

## Файлы

- `index.html` — элементы экрана и встроенные SVG из Figma.
- `assets/` — пингвин, снежная шапка, контуры текста задачи и шторки, графика экрана успеха из Figma. Фоновый снег и статус-бар берутся из `gift-appearance/assets/`.
- `styles.css` — оформление, доска из 64 клеток, бабл, шторка и экран успеха.
- `app.js` — состояния и анимации на Anime.js.
- `../motion/success-reveal.js` — общее снежное раскрытие экрана успеха и подарка.
- `vendor/` — Anime.js 3.2.2 и лицензия MIT.

Тексты задач 2–5 демонстрационные. Шторка появляется за 460 мс и закрывается за 260 мс. Выход из пятой задачи занимает 900 мс. Затем идут белая пауза 500 мс и анимация экрана успеха 3280 мс.

[Открыть прототип в GitHub Pages](https://folamhmark.github.io/T-Chess/daily-tasks-animation/)

## Прогресс задач

Верхний бар показывает долю завершённых задач от 0 до 100%. Он растёт при появлении шторки «Верный ход» и сохраняет значение при продолжении и повторе. После финала результат 5 из 5 сохраняется до запуска нового круга или выбора задачи в панели. Выбор задачи цифрой задаёт соответствующее число предыдущих завершённых задач. Escape закрывает шторку и сохраняет уже засчитанный результат.

Заполнение занимает 620 мс с плавным торможением. При уменьшении движения значение меняется сразу.
