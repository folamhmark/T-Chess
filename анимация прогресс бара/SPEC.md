# Спецификация анимации прогресс-бара

Версия: 1.0 · 16 ноября 2026 года.

[Прототип](https://chess-marathon-progress-anim.folamhmark.chatgpt.site) · [Запуск и структура файлов](README.md)

## Назначение

Компонент «Путь к призам» показывает прогресс шахматного марафона: от 0 до 20 активных дней. При зачёте нового дня обновляются счётчик, точки, состояние иконки этапа и нижняя подпись.

Один активный день засчитывается за урок или задачу дня. За одни календарные сутки можно получить один активный день. В прототипе зачёт запускается вручную; календарь, сохранение прогресса и проверка выполнения задания не реализованы.

## Данные и состояния

Для интеграции компоненту нужны:

| Поле | Значение |
| --- | --- |
| `activeDays` | Целое число от 0 до 20 — число засчитанных активных дней. |
| `todayCredited` | Засчитан ли текущий календарный день. Независимо от общего прогресса. |
| `previousActiveDays` | Предыдущее подтверждённое значение для анимации нового дня. |
| `reducedMotion` | Системная настройка уменьшения движения. |

Это контракт для интеграции, а не готовый API текущего файла. В `app.js` используются демонстрационные переменные `from`, `to`, `current`, `credited` и `busy`; они не сохраняются после перезагрузки.

| Состояние | Отображение |
| --- | --- |
| День ещё не засчитан | Нижняя подпись «Сегодняшний день не засчитан», цвет основного текста. |
| Идёт зачёт | Текущий прогресс плавно переходит к новому значению. Повторный запуск заблокирован. |
| День засчитан | Нижняя подпись «Сегодняшний день засчитан», цвет `#428BF9`. |
| Достигнуто 10 дней | Иконка подарка становится активной; участки точек перестраиваются. |
| Достигнуто 20 дней | Кубок становится активным. Всплывающего поздравления нет. |

Для продукта подтверждение зачёта должно приходить из системы прогресса. Повторное открытие экрана с тем же значением не должно воспроизводить зачёт ещё раз. Демо-кнопка «Повторить анимацию» предназначена только для просмотра эффекта.

## Состав и геометрия

Эталонный размер мобильного экрана — 375 × 812 px. Карточка расположена на расстоянии 16 px от левого края и 104 px от верхнего. Ширина карточки — 343 px, горизонтальные внутренние отступы — 20 px; ширина ряда прогресса — 303 px.

| Элемент | Размер / значение |
| --- | --- |
| Заголовок | «Путь к призам», 20 px. |
| Счётчик | «N из 20 активных дней», 14 px. |
| Ряд прогресса | Высота 32 px, все элементы выровнены по вертикальному центру. |
| Обычная точка дня | **8 × 8 px**, круг. |
| Маленькая точка свёрнутого участка | **4 × 4 px**, круг. |
| Промежуток между маленькими точками | **4 px между краями**; расстояние между центрами — 8 px. |
| Группа маленьких точек | Ровно 3 точки, общая ширина **20 px**. |
| Иконка этапа вместе с кругом | **32 × 32 px**. |
| Нижняя подпись | 14 px. |

Три маленькие точки распределяются как одна компактная группа. Они не растягиваются на всю ширину участка. Остальные промежутки рассчитываются из доступной ширины ряда: `(ширина ряда − суммарная ширина элементов и групп) / число промежутков`. При анимации размеры и позиции интерполируются плавно.

Фон экрана — голубой градиент `linear-gradient(155deg, #F5F9FF 0%, #DCE8F8 48%, #BFD3ED 100%)`. Карта и пингвин удалены.

## Иконки и цвета

| День | Иконка | Условие активного состояния |
| --- | --- | --- |
| 1 | Солнце | `activeDays >= 1` |
| 10 | Подарок | `activeDays >= 10` |
| 20 | Кубок | `activeDays >= 20` |

Активная иконка: синий круг `#428BF9`, белый символ. У солнца центр с голубым градиентом и тонкая синяя обводка.

Неактивная иконка: белый круг, тонкая светлая обводка `#EDEDEE`, серый символ `#979DA7`. У солнца центр с серым градиентом. У подарка в неактивном варианте заполненные серые части коробки; при активации они плавно сменяются белым контурным рисунком. Кубок сохраняет вырез звезды в цвет фона круга.

Иконки воссозданы в SVG по предоставленным активным и неактивным изображениям. Они находятся в `index.html` в символах `progress-sun`, `progress-gift`, `progress-cup`.

Обычная незасчитанная точка имеет цвет `#EDEDEE`, засчитанная — `#428BF9`. Нижняя подпись неактивного дня — `#343638`, засчитанного — `#428BF9`. Счётчик остаётся цветом основного текста.

## Сворачивание участков

Путь состоит из солнца на 1-м дне, точек 2–9, подарка на 10-м дне, точек 11–19 и кубка на 20-м дне.

| Прогресс | Между солнцем и подарком | Между подарком и кубком |
| --- | --- | --- |
| 0–9 дней | 8 обычных точек, по одной на дни 2–9. | Группа из 3 маленьких серых точек. |
| 10–20 дней | Группа из 3 маленьких синих точек пройденного участка. | 9 обычных точек, по одной на дни 11–19. |

На переходе **9 → 10** первая последовательность схлопывается в группу из трёх точек, вторая раскрывается в девять обычных точек. Одновременно активируется подарок.

В конечном состоянии 20 дней текущий прототип сохраняет второй участок раскрытым. Это зафиксированное поведение текущей версии.

Маленькие точки — условное обозначение участка, а не три отдельных дня. Они не меняют значение счётчика и не участвуют в вычислении количества заработанных дней.

## Анимация зачёта

Используется Anime.js 3.2.2 и единая временная шкала. Характер движения вдохновлён richbox: лёгкое предварительное сжатие, затем мягкое возвращение без увеличения выше исходного размера.

Общая длительность обычного зачёта — **1000 мс**. Для этапов 1, 10 и 20 — **1180 мс**. В конце временной шкалы итоговый вид удерживается.

| Время от запуска | Изменение |
| --- | --- |
| 0–150 мс | Новый маркер сжимается от масштаба 1 до 0,9 с плавным началом и концом. |
| 150–800 мс | Маркер возвращается от 0,9 до 1; заливка переходит к активному цвету. Для иконки меняются фон, цвет символа и рисунок подарка. |
| 150–430 мс | Старые значения счётчика и нижней подписи исчезают. Счётчик смещается вверх до 5 px, подпись — до 2 px. |
| Около 430 мс | Текст заменяется в момент нулевой прозрачности. |
| 430–710 мс | Появляются новое число и синяя подпись. Счётчик поднимается из смещения +5 px в 0, подпись — из +2 px в 0. |
| 210–950 мс | Интерполируются позиции, размеры и прозрачность точек; на 9 → 10 происходит сворачивание и раскрытие участков. |
| Конец | Фиксируются новое значение и доступность повторного запуска в демо. |

Для плавного сжатия используется `smoothstep(t) = t² × (3 − 2t)`. Для мягкого возвращения и изменения геометрии — нормированная функция `spring(t) = (1 − (1 + 8t) × exp(−8t)) / (1 − 9 × exp(−8))`, где `t` ограничен диапазоном 0…1. Значения берутся из текущего видимого состояния, чтобы прерывание не вызывало скачка.

**Не показывать:** расширяющиеся ореолы, большие внешние кольца, конфетти и всплывающую плашку получения приза. Статические круги самих иконок остаются размером 32 × 32 px.

## Управление в демонстрации

- Выбор перехода: 0→1, 2→3, 9→10, 10→11, 19→20.
- «Засчитать день» запускает переход; на мобильном экране его также запускает кнопка урока.
- «Повторить анимацию» возвращает выбранное начальное состояние и воспроизводит тот же переход.
- «Сбросить переход» возвращает начальное состояние; смена сценария перестраивает ряд за 440 мс с `cubic-bezier(.22, 1, .36, 1)`.
- Во время зачёта кнопка запуска и замедление заблокированы. Можно выбрать другой сценарий или сбросить текущий; старый переход отменяется.
- «Замедлить ×3» увеличивает длительность зачёта втрое; это инструмент просмотра, не настройка продукта.
- Кнопка `?` открывает подсказку о правилах зачёта. Повторное нажатие, клик вне подсказки и Escape закрывают её.
- Нижняя навигация и «Закрыть» — демонстрационные элементы, без перехода на другие экраны приложения.

## Доступность и уменьшение движения

Ряд имеет `role="progressbar"`, минимум 0, максимум 20 и текущее числовое значение. Изменение нижней подписи объявляется через `aria-live="polite"`; скрытые при сворачивании точки исключаются из доступного представления.

При `prefers-reduced-motion: reduce` устанавливается итоговое состояние без движения, с теми же цветами, числом точек и подписью. Если настройка включена во время зачёта, движение останавливается и показывается его итог. Управление доступно с клавиатуры, виден фокус.

## Проверка при реализации

1. На 0 → 1 активируется солнце; подпись становится синей.
2. На 2 → 3 активируется только следующая точка; уже накопленный прогресс не проигрывается заново.
3. На 9 → 10 открывается подарок, первая группа плавно сворачивается до трёх точек 4 × 4 px с промежутками 4 px; вторая раскрывается.
4. На 10 → 11 активируется первая обычная точка после подарка. Обычная точка — 8 × 8 px в установившемся состоянии.
5. На 19 → 20 активируется кубок, счётчик достигает 20, всплывающей плашки нет.
6. Неактивные иконки серые на белом круге, активные — белые на синем. Размер иконок в обоих состояниях — 32 × 32 px.
7. При сбросе возвращаются исходный счётчик, раскладка и тёмная подпись незасчитанного дня.
8. Быстрая смена сценария не оставляет незавершённую анимацию или неверное количество точек.
9. В режиме уменьшенного движения все состояния достигаются без анимации.
10. Переходы не дают горизонтального выхода за границы ряда и не меняют размеры карточки.

## Границы прототипа

Прототип работает локально в браузере, без сборки, API и хранения пользовательских данных. Реальная выдача призов, определение календарных суток и часового пояса, синхронизация между устройствами и серверное подтверждение зачёта должны быть подключены в основном приложении. Эта версия описывает визуальный компонент и его демонстрационные переходы.
